Cấu Hình Kết Nối Google Sheet

Dán đường dẫn Web App đã triển khai từ Google Sheets của bạn vào đây.

Hướng Dẫn Lấy Link Web App trong 3 Bước:

  1. Mở file Google Sheet 1841 - CA HÀNH CHÍNH > Vào Tiện ích mở rộng > Apps Script.
  2. Dán mã nguồn từ file Code.gs vào và bấm nút 💾 Lưu dự án.
  3. Bấm nút Triển khai (Deploy) > Triển khai mới (New deployment) > Chọn loại Ứng dụng web (Web app):
    • Thực thi dưới dạng: Tôi (Me)
    • Ai có quyền truy cập: Bất kỳ ai (Anyone)
  4. Sao chép URL Web App vừa tạo và dán vào ô bên trên rồi bấm Lưu cấu hình.
